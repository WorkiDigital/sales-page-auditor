# Examples

Este diretório contém dados **fictícios** de exemplo, usados apenas para
ilustrar o formato produzido por `scripts/capture.mjs` e para servir de
referência ao escrever um relatório a partir de `REPORT_TEMPLATE.md`.

- `example-evidence.json` — formato de `evidence.json` para uma página
  fictícia ("Curso Fictício X"). Nenhum dado aqui corresponde a uma página
  real ou cliente real.

Nunca coloque uma captura real de cliente aqui — capturas reais vão em
`output/`, que é ignorado pelo Git.
