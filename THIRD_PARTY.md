# Atribuições e dependências de referência

Este projeto usa uma síntese original de metodologias, sem incluir arquivos das skills de terceiros. A instalação e a execução não fazem clone ou download de scripts dessas fontes.

- Corey Haines — Marketing Skills (MIT): https://github.com/coreyhaines31/marketingskills. Referência: copywriting, CRO, revisão, marketing psychology e ofertas.
- Rob Palmer — Claude Code Copywriting Skills (CC BY 4.0): https://github.com/robpalmer99/claude-code-copywriting-skills. Referência: direct-response-copy, landing-page-copy, copychief, compliance-checker. Atribuição ao criador conforme licença.
- Anthropic — Frontend Design: https://github.com/anthropics/skills/tree/main/skills/frontend-design. Referência conceitual para design. Os arquivos têm termos específicos e não foram redistribuídos.

Biblioteca de execução: Playwright, licença Apache-2.0. Ver https://github.com/microsoft/playwright.

Nada aqui implica certificação, associação formal ou endosso pelos autores. Sua documentação original é a referência para detalhes de cada skill.
